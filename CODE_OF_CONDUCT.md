# Code of conduct

Termoso is built by people who want a tool that respects its users. The same
respect applies to each other.

## Expected

* Be direct and kind. Critique code and ideas, not people.
* Assume good faith; ask before concluding.
* Give newcomers the context you wish you had had.
* Keep discussions in issues and pull requests on the technical point.
* Respect people's time: read before asking, test before submitting.

## Not tolerated

* Harassment, discrimination or personal attacks of any kind, including
  based on gender, sexuality, disability, ethnicity, religion, nationality,
  age or experience level.
* Publishing others' private information.
* Sustained disruption of discussions, trolling or bad-faith reporting.
* Advocating for or threatening any of the above.

## Scope

This applies in the repository (issues, pull requests, discussions, commit
messages, reviews) and anywhere you represent the project.

## Enforcement

Report problems to the maintainers privately through
<https://github.com/rep0rtDev/termoso/security/advisories/new> (pick the
"other" category) or by contacting a maintainer listed in
`.github/CODEOWNERS`. Reports are handled confidentially. Consequences range
from a warning to removal from the project at the maintainers' discretion.

Adapted in spirit from the Contributor Covenant 2.1.
