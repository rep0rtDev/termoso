## Layout

The terminal uses the whole screen. Above the keyboard sits the **session bar**: tabs of open sessions, the AI button, a key button for hidden input, and quick keys like <kbd>esc</kbd>, <kbd>tab</kbd> and <kbd>ctrl</kbd>. The first **Back** hides the keyboard; the second leaves the terminal.

![Android terminal with the session bar](/docs/img/android-terminal.png)

## Key panel

Expand the panel for rows of extra keys: arrows and editing keys, navigation (Home, End, PgUp, PgDn), symbols, brackets, F1–F12 and a **tmux** row with the common `Ctrl-B` chords (new window, next, previous, detach, split, zoom, copy mode…). **Settings → Keyboard & gestures** lets you reorder, hide or add rows.

![Extra key rows](/docs/img/android-keys.png)

## Gestures and buttons

- Pinch to change the text size.
- Swipe horizontally to move the cursor; a two-finger swipe switches sessions.
- Volume buttons and **Shake the device** can be bound to actions such as Tab, Esc, arrows or paste.

## Connections

The **Connections** tab shows each open session as a live preview of its screen. Tap one to return to it, or close it from the card.

![Live session previews](/docs/img/android-connections.png)

## Sharing text into the terminal

Share text from any app to Termoso and it is offered for pasting into the active session, with a preview first so nothing runs by accident.
