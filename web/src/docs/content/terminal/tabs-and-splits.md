## Tabs

Each session opens in its own tab. Drag tabs to reorder them. Right-click a tab (or use its menu) for **Split right**, **Split down**, **Duplicate session**, **Broadcast input to all panes**, **Find**, **Clear buffer**, **Save as workspace template**, **Close others** and **Close**.

![Tab menu](/docs/img/desktop-tab-menu.png)

## Splits

A tab can hold up to sixteen panes. Split with the tab menu, drag the divider to resize, and click a pane to focus it — the focused pane has a highlighted frame. Each pane has its own header with the host's OS icon, name and address, and buttons for broadcast, its menu and closing it.

![Two panes in one tab](/docs/img/desktop-split.png)

## Broadcast input

**Broadcast input to all panes** sends every keystroke to all panes of the tab at once — useful for running the same command on a fleet. The pane headers show which panes receive input; turn it off from the same menu.

## Workspaces

**Save as workspace template** stores the layout of the current tab — which hosts, in which panes — under a name. Open a template from **New tab** to reconnect the whole layout in one step. On start-up the app can also restore the tabs that were open when it was closed.

## Side panel

The button on the right of the title bar opens the side panel of the current session: terminal search and settings, snippets, and the port-forwarding rules of the host.

## Command palette and shortcuts

<kbd>Ctrl</kbd>+<kbd>K</kbd> (<kbd>⌘</kbd>+<kbd>K</kbd> on macOS) opens the command palette to jump to a host, a tab or an action. Every shortcut can be changed in **Settings → Keyboard shortcuts**.
