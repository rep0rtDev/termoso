---
title: Quick start
description: Install the app, add a host and connect — in about a minute, with or without an account.
---

## 1. Install

Grab the build for your platform from the [download page](/docs/getting-started/download). The desktop app starts in a **Local vault**: nothing is synced until you decide to sign in.

## 2. Add a host

Type `user@host:port` into the search field on the Hosts screen and press <kbd>Enter</kbd> to connect right away, or press **New host** to fill in the details and save them.

![The Hosts screen with the host details panel open](/docs/img/desktop-hosts.png)

## 3. Connect

The first connection to a server shows its host key fingerprint. Confirm it once; the key is pinned in **Known hosts** and a change is flagged on later connections. Passwords and passphrases are asked for inline, in the connection card.

## 4. Optional: sign in

An account adds sync between devices and sharing with a team. Use the free cloud at `app.termoso.dev` or [your own server](/docs/self-hosting/overview) — the app asks for the server URL when you sign in.
